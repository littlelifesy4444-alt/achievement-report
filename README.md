# 성취도평가 웹앱

## 이 웹앱이 하는 일
1. 시험지 PDF 업로드
2. 공식 정답표/채점기준 업로드 (선택)
3. 학생 답안 PDF/JPG/PNG 여러 개 업로드
4. 시험 문항별 분석
5. 학생별 자동 채점
6. 영역별 성취도 및 오답 진단 계산
7. 매뉴얼 형식의 Word 리포트 생성
8. 학생별 Word 파일 또는 ZIP으로 다운로드

## 학생 답안 준비
- 가장 권장: 학생 1명당 PDF 1개
- 파일명 예: `2-1_홍길동.pdf`
- 답안이 이미지 1장이라면 JPG/PNG도 가능
- 여러 장의 이미지로 된 한 학생 답안은 먼저 하나의 PDF로 합치는 것을 권장

## 실행 방법 A - Streamlit Community Cloud에 배포
이 폴더를 GitHub 저장소에 올린 뒤 Streamlit Community Cloud에서 `app.py`를 배포합니다.
Secrets에 다음 값을 설정하면 사용자 화면에서 API 키를 입력하지 않아도 됩니다.

```
OPENAI_API_KEY = "sk-..."
```

## 실행 방법 B - PC에서 임시 실행
Python이 설치된 PC에서:

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 열리면 태블릿/휴대폰에서도 같은 네트워크 주소로 접속할 수 있습니다.

## 주의
- OpenAI API 사용료는 ChatGPT 구독과 별도입니다.
- 시험지와 학생 답안은 분석을 위해 OpenAI API로 전송됩니다.
- 공식 정답표가 없으면 시험지 분석으로 정답을 판단하되, 모호한 문항은 확인 필요/채점 제외로 처리하도록 설계했습니다.
- 웹앱은 생성된 리포트와 함께 `_시험분석_검수용.json`을 ZIP 안에 넣습니다.
- 실제 성적 배포 전에는 확인/제외 문항이 없는지 검수하는 것을 권장합니다.
